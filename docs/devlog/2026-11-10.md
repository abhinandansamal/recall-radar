## Decisions / learnings
- ADR-0002: pydantic-settings + structlog; correlation IDs via contextvars (each asyncio task keeps its own)
- CI runner pinned to ubuntu-24.04 (ubuntu-latest moves to Ubuntu 26)
- gitleaks ignores AWS "EXAMPLE" keys by design; proof uses a random token-shaped value outside the repo
- Yesterday: CI failed twice with a GitHub "Internal server error"; an empty commit started a fresh run
- TDD: tests describe the wanted behaviour before the code exists; a red run proves the test can fail
- Pylance: `@contextmanager` with `-> Iterator[...]` is deprecated; use `-> Generator[str, None, None]`
- Editor import sorting put `rr_core` among third-party imports; fixed with `known-first-party = ["rr_core"]` and the Ruff VS Code extension
