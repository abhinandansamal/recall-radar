## Decisions / learnings
- Phase 0 check: PRD covered product scope; engineering requirements (reversibility of actions, catastrophic errors, component metrics, EU-only processing, retention, golden sets) added in the design brief.
- Remote state is created by a bootstrap script, because Terraform needs its state storage before it can create anything.
- State access uses Entra ID (`use_azuread_auth`), not storage keys; shared-key access disabled.
- Cost layout: dev = laptop (Docker); Azure holds test and prod; expensive pieces (Postgres, Databricks) shared.
- AzureRM 5.13.0 / random 3.9.1 pinned in `.terraform.lock.hcl`; AzureRM 5 no longer registers resource providers automatically, so they were registered once with `az provider register`.
- test and prod use the same module, each with its own state file (`test.tfstate`, `prod.tfstate`): a mistake in one cannot touch the other.
- Log Analytics daily cap 0.5 GB per environment (US-005); Key Vault in RBAC mode; private endpoint noted as production hardening (cost).
- Plan files (`tfplan`) are git-ignored: they can contain sensitive values.
- Draft PR #34 used to run CI on unfinished work; it cannot be merged until marked ready.
- Sprint re-plan: Sprint 1 had 8 of 12 stories open on its last day. Product Owner decision: Sprint 1 extended to 13 Nov (F02 to F05); Sprint 2 = 14–16 Nov; Sprint 3 = 17–19 Nov; final release date unchanged (19 Nov). Scope cut (stretch list) to be confirmed at the Sprint 1 review.
