## Decisions / learnings
- Shared stack for expensive resources: one free Postgres server (databases per environment) and one Databricks workspace (catalogs per environment).
- Postgres flexible server is not offered in Germany West Central (nor West Europe) for this subscription: the API answered "Version should be in: []". An empty list of allowed values means "not available here", not "wrong value". Checked EU regions with `az postgres flexible-server list-skus`; moved Postgres to France Central with a variable. Still EU-only; design brief updated.
- A failed apply is not lost work: Terraform kept the 10 created resources in state; the next plan contained only the 5 missing ones.
- Unity Catalog in an automatically enabled workspace: each new catalog needs its own storage location; workspace admins can create storage credentials, external locations and catalogs.
- Lake storage has shared keys disabled; Terraform uses Entra ID (`storage_use_azuread = true`).
- Postgres admin password generated by Terraform (`random_password`), shown only as a sensitive output; apps get their own least-privilege users in F05.
- Read the plan before applying: a typo (`glod`) created a wrong schema. Renaming in Terraform means destroy + create; the plan showed 3 to add, 3 to destroy.
- YAML: a multi-line `run:` needs `run: |`. Without the `|` the lines are folded into one command ("No positional arguments").
- CI failed once on an HTTP 500 while downloading a provider from github.com. Not our bug; `gh run rerun --failed` fixed it.
- OIDC: AADSTS700213 = the federated credential's subject does not match the token. GitHub sends `repo:owner@<owner_id>/repo@<repo_id>:...` with immutable IDs (a re-created repo with the same name can't reuse the trust). Fixed by copying the exact subject from the error; the setup script now builds it from `gh api`.
- Pre-commit: after "files were modified by this hook", always `git add` again. Committing without it gives "Stashed changes conflicted with hook auto-fixes… Rolling back".
- Zsh: `<name>` in instructions is a placeholder. Typed literally, `<` means "read from file".
- Azure budgets live at a scope (billing account, subscription, resource group). `az consumption budget list` only shows the current subscription's budgets, so check the scope before concluding a budget is missing.
