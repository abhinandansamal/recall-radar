## Decisions / learnings
- Shared stack for expensive resources: one free Postgres server (databases per environment) and one Databricks workspace (catalogs per environment).
- Postgres flexible server is not offered in Germany West Central (nor West Europe) for this subscription: the API answered "Version should be in: []". An empty list of allowed values means "not available here", not "wrong value". Checked EU regions with `az postgres flexible-server list-skus`; moved Postgres to France Central with a variable. Still EU-only; design brief updated.
- A failed apply is not lost work: Terraform kept the 10 created resources in state; the next plan contained only the 5 missing ones.
- Unity Catalog in an automatically enabled workspace: each new catalog needs its own storage location; workspace admins can create storage credentials, external locations and catalogs.
- Lake storage has shared keys disabled; Terraform uses Entra ID (`storage_use_azuread = true`).
- Postgres admin password generated by Terraform (`random_password`), shown only as a sensitive output; apps get their own least-privilege users in F05.
