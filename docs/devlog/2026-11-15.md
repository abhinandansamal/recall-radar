## Decisions / learnings
- **Export through files, not a direct write:** Databricks serverless cannot pass the Postgres firewall (fixed outbound IPs for non-storage Azure resources need the Databricks account team or a paid private endpoint). Gold writes an export with a manifest; the exporter runs where Postgres is reachable (laptop for dev, Container Apps job later). The lake never needs database passwords.
- **One contract module** (`rr_export/kb_schema.py`) for gold notebook, exporter and contract tests; `SCHEMA_VERSION` must change with the schema.
- **Test the failure paths:** wrong counts, a broken reference, an invalid value or a second exporter all leave `kb` unchanged (integration tests). The ERRORs in the Postgres log during tests are these deliberate cases.
- **Strict Spark on serverless:** reading the first item of an empty array is an error, not NULL; use `F.get(array, 0)`. Found by running the notebooks on local Spark before Databricks.
- **ABO licence is contradictory** (README: CC BY 4.0; AWS registry: CC BY-NC 4.0): recorded both; non-commercial use with attribution satisfies both.
- **Keyword proposals need human review:** "Lighting chains" was picked for bulbs (alphabetical match), jewellery types without underscores were missed, phone covers were proposed as electrical appliances. The PO reviewed all 576 types; footwear kept (PO decision).
- **Honest numbers:** 78.7 % of alerts are in categories with at least one ABO listing, but only 53.1 % with at least 100. ABO has no barcodes, almost no toys and no vehicles.
- **Cosmetic data issue:** titles like "Raincoat - Raincoat" when product type and name are equal; fixed in gold.
- **Docker Desktop hung:** every `docker` command waited forever because `com.docker.backend` was stuck. Fix: end the stuck processes (`kill -9` on the backend), start Docker once, `make up`. Never use "Reset to factory defaults" (deletes volumes).
