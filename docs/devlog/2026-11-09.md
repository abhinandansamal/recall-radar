## Decisions / learnings
- Full listing titles never find alerts; barcode search returns nothing although alerts contain the EAN.
  These two findings define the matching requirements (exact keys + cross-language + image).
- Study design flaw found and fixed before timing: photo URLs revealed the answer; test run blind.
- Manually created Databricks workspace (Premium tier) is temporary; Terraform creates the real
  environments in F02, then the manual resource group is deleted.
- Roadmap milestone markers only appear for milestones used by items in the view; epics got sprint milestones.
- `.gitignore` rule `reports/` also hid `evals/reports/`; changed to `/reports/`.
- After a squash merge, delete the local branch with `git branch -D`.
- Numbers saves `.numbers` even when the name ends in `.csv`: use File → Export To → CSV.
